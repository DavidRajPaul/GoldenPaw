# GoldenPaw website

Static pages for the stores and the app: privacy policy, terms of use, account deletion, support.
Built by GitHub Pages (Jekyll) from this folder via `.github/workflows/pages.yml`.

1. Fill the TODO values in `_config.yml` (and review the policy text).
2. GitHub → Settings → Pages → Source: **GitHub Actions**.
3. GitHub → Settings → Secrets and variables → Actions → **Variables** → `PAGES_ENABLED` = `true`.
4. Actions → "Website" → Run workflow. The site appears at https://davidrajpaul.github.io/GoldenPaw/.

URLs for the stores and the app (`goldenpaw.privacyUrl`):

| Page | Path |
|---|---|
| Privacy policy | `/privacy/` |
| Terms of use | `/terms/` |
| Delete account & data | `/delete-account/` |
| Support | `/support/` |
